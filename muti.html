展开：参考答案与解析

1. C（集合运算（不等式做背景）｜2023）

【思路】 先解不等式求出集合 $N$，再与有限集 $M$ 求交集。 【解答】 由 $x^2-x-6 \ge 0$ 得 $(x-3)(x+2) \ge 0$，所以 $N=(-\infty,-2] \cup [3,+\infty)$。 又 $M=\{-2,-1,0,1,2\}$，故 $M \cap N = \{-2\}$。故选C。

2. A（充分必要条件｜2020）

【思路】 判断充分性和必要性：先看 $a=0$ 是否能推出 $M \subseteq N$，再看 $M \subseteq N$ 时 $a$ 是否只能为 $0$。 【解答】 当 $a=0$ 时，$M=\{1,0\}$，$N=\{-1,0,1\}$，显然 $M \subseteq N$，充分性成立。 若 $M \subseteq N$，则 $a \in N$，且 $a \neq 1$，所以 $a=0$ 或 $a=-1$，必要性不成立。 因此“$a=0$”是“$M \subseteq N$”的充分不必要条件。故选A。

3. (-1, \frac{2}{3})（一元二次/分式不等式｜2019）

【思路】 将二次三项式因式分解，利用一元二次不等式的解法求范围。 【解答】 由 $3x^2+x-2<0$ 得 $(x+1)(3x-2)<0$，解得 $-1<x<\frac{2}{3}$，所以 $x$ 的取值范围是 $(-1,\frac{2}{3})$。故填 $(-1,\frac{2}{3})$。

4. C（基本不等式求最值｜2021）

【思路】 分别利用二次函数、基本不等式和对数函数性质判断各选项的最小值，注意基本不等式取等条件及变量的取值范围。 【解答】 对于 A，$y=x^2+2x+4=(x+1)^2+3\ge 3$，当 $x=-1$ 时取等号，最小值为 3，不符合。 对于 B，令 $t=|\sin x|$，则 $t\in(0,1]$，$y=t+\frac{4}{t}$。由对勾函数性质，$y$ 在 $(0,1]$ 上单调递减，故 $t=1$ 时取最小值 $5$，不符合。 对于 C，$y=2^x+2^{2-x}=2^x+\frac{4}{2^x}\ge 2\sqrt{2^x\cdot\frac{4}{2^x}}=4$，当且仅当 $2^x=\frac{4}{2^x}$，即 $x=1$ 时取等号，最小值为 4，符合。 对于 D，当 $\ln x<0$ 时，$y=\ln x+\frac{4}{\ln x}<0$，最小值小于 4，不符合。 故选 C。

5. B（指对数比大小｜2018）

【思路】 利用换底公式将 $\frac1a$ 和 $\frac1b$ 化为同底对数，判断 $\frac{a+b}{ab}$ 的范围，再结合 $a,b$ 的符号确定大小关系。 【解答】 由换底公式， \[ \frac1a=\log_{0.3}0.2,\quad \frac1b=\log_{0.3}2, \] 所以 \[ \frac1a+\frac1b=\log_{0.3}0.2+\log_{0.3}2=\log_{0.3}0.4. \] 因为 $0<0.3<1$，$0<0.4<1$，所以 $\log_{0.3}0.4>0$；又 $0.4<1$，底数 $0.3<1$，故 $\log_{0.3}0.4<\log_{0.3}0.3=1$。因此 \[ 0<\frac1a+\frac1b<1,\quad 即\ 0<\frac{a+b}{ab}<1. \] 又 $a=\log_{0.2}0.3>0$，$b=\log_2 0.3<0$，所以 $ab<0$。由 $\frac{a+b}{ab}>0$ 且 $ab<0$，得 $a+b<0$，从而 $ab<a+b<0$。 故选 B。

6. A（函数性质综合（奇偶+周期）｜2025）

【思路】 利用偶函数和周期为 2 的性质，将 $f(-\frac{3}{4})$ 转化为已知区间 $[2,3]$ 上的函数值。 【解答】 因为 $f$ 是偶函数，所以 $f(-\frac{3}{4})=f(\frac{3}{4})$。又周期为 2，所以 $f(\frac{3}{4})=f(\frac{3}{4}+2)=f(\frac{11}{4})$。由于 $2\le \frac{11}{4}\le 3$，故 $f(\frac{11}{4})=5-2\times\frac{11}{4}=5-\frac{11}{2}=-\frac{1}{2}$。故选 A。

7. B（三角恒等变换求值｜2023）

【思路】 由已知差角正弦公式可先求出 $\sin\alpha\cos\beta$，进而得到 $\sin(\alpha+\beta)$，再利用二倍角公式求 $\cos(2\alpha+2\beta)$。 【解答】 由 $\sin(\alpha-\beta)=\sin\alpha\cos\beta-\cos\alpha\sin\beta=\frac13$，且 $\cos\alpha\sin\beta=\frac16$，得 $\sin\alpha\cos\beta=\frac13+\frac16=\frac12$。于是 $\sin(\alpha+\beta)=\sin\alpha\cos\beta+\cos\alpha\sin\beta=\frac12+\frac16=\frac23$。所以 $\cos(2\alpha+2\beta)=\cos[2(\alpha+\beta)]=1-2\sin^2(\alpha+\beta)=1-2\times\left(\frac23\right)^2=1-\frac89=\frac19$。故选B。

8. B（y=Asin(ωx+φ) 的图象与性质｜2025）

【思路】 正切函数的对称中心满足 $x-\frac{\pi}{3}=\frac{k\pi}{2}$，解出 $a$ 后取最小正值。 【解答】 由题意，$a-\frac{\pi}{3}=\frac{k\pi}{2}$（$k\in\mathbb{Z}$），所以 $a=\frac{\pi}{3}+\frac{k\pi}{2}$。因为 $a>0$，当 $k=0$ 时取得最小值 $\frac{\pi}{3}$。故选 B。

9. C（图象交点与零点个数｜2024）

什么叫"母题"：一个模型 = 一类题的公共骨架。母题会了，同族的变式都能推。

用法：先看"题眼"能不能一眼认出来，再看"通法"是不是闭着眼能走完。认不出眼，就得回去补这一节。

  • 机械能守恒｜题眼：只有重力（或弹力）做功，或其它力做功之和为零｜通法：选零势能面 → 列 Ek1+Ep1=Ek2+Ep2；自由落体、光滑斜面下滑、光滑圆弧是典型场景。
  • 动量与碰撞（一维）｜题眼：看到"碰撞""爆炸""反冲"就想动量守恒；"弹性"再叠加动能守恒｜通法：取正方向 → m₁v₁=m₁v₁′+m₂v₂′；弹性碰撞用 v₁′=(m₁−m₂)/(m₁+m₂)·v₁、v₂′=2m₁/(m₁+m₂)·v₁；完全非弹性则碰后共速。
  • 人船模型｜题眼："人动船退"、系统初动量为零、不计阻力｜通法：由 m人·x人 = M船·x船 与位移关系 x人 ± x船 = L 联立，求各自位移（方向相反）。

高二

  • 电场 · 库仑定律与场强｜题眼："两个（点）电荷""静电力"→ 库仑定律；"匀强电场"→ E=U/d；"场强叠加"→ 矢量合成｜通法：F=kq₁q₂/r²（同号斥、异号吸）；点电荷场强 E=kQ/r²；匀强电场 E=U/d。
  • 电势能与电容｜题眼：平行板电容器 C=Q/U、C=εS/(4πkd)、E=U/d；"断开电源"Q 不变、"始终接电源"U 不变｜通法：先判断 Q 或 U 哪个量不变，再用 C=Q/U 与 E=U/d 联推。
  • 闭合电路欧姆定律｜题眼：题目给了电源内阻 r，或要你求"路端电压 / 输出功率"｜通法：I=E/(R+r) → U=IR=E−Ir → P出=UI=I²R；注意输出功率最大时 R=r。
  • 电表改装与伏安法｜题眼：给了表头 Ig、Rg；"改装成电压表"串、"改装成电流表"并｜通法：电压表串联 R=U/Ig−Rg；电流表并联 R′=IgRg/(I−Ig)；测电阻时大电阻用内接、小电阻用外接（看谁的分流/分压可忽略）。
  • 磁场 · 安培力与洛伦兹力｜题眼：通电导线在磁场中（F=BIL）、运动电荷在磁场中（F=qvB）｜通法：先确认 B 与 I（或 v）是否垂直，垂直才用 F=BIL、F=qvB；方向用左手定则。
  • 带电粒子在磁场中的圆周运动｜题眼：v⊥B、不计重力 → 匀速圆周，洛伦兹力提供向心力｜通法：qvB=mv²/r → r=mv/(qB)，T=2πm/(qB)（周期与 v、r 无关）。
  • 电磁感应 · 楞次定律与动生电动势｜题眼："导体棒切割磁感线""磁通量变化"；判电流方向用楞次（增反减同、来拒去留）｜通法：E=BLv（v、B、L 两两垂直）或 E=nΔΦ/Δt；闭合回路 I=E/R；安培力方向总阻碍相对运动。
  • 交变电流与变压器｜题眼：理想变压器 U₁/U₂=n₁/n₂、I₁/I₂=n₂/n₁、P₁=P₂｜通法：先由匝数比求副线圈电压 → 由负载求 I₂ → 再用功率守恒求 I₁。
  • 机械波与波的图象｜题眼：v=λf=λ/T；"沿传播方向，后一质点总落后前一质点"｜通法：由 v、λ、T、f 中任意两个求其余；结合图象读振幅、由传播方向判质点振动方向（反之亦然）。

三句话总结

1. 高一上练"力与加速度"：把受力分析做干净，再用牛顿第二定律联系运动——重点在"过程分段"与"临界时刻"；

2. 高一下练"两个守恒"：能量（动能定理、机械能守恒）和动量（碰撞、人船），先想守恒、再列式；

3. 高二练"场与路"：从均匀场的受力，到磁场中的圆周，再到电磁感应与交变电流——重点在"判断方向 + 抓住不变的量"。

展开：参考答案与解析

1. C（运动学图象与匀变速直线运动）

【思路】 先判断减速停下所需时间，确认 6 s 内是否已停止。

【解答】 由 v₀ = at 得停下所需时间 t₀ = v₀/a = 10/2 = 5 s < 6 s，故 5 s 时车已停。位移只算到停下：x = v₀²/(2a) = 10²/(2×2) = 25 m。故选 C。

2.（追及相遇）

【思路】 两车速度相等时相距最近；再比较最小间距与 0 的大小判断是否相撞。

【解答】 (1) 汽车减速到与拖拉机同速（4 m/s）时两者距离最小，用时 t = (12−4)/2 = 4 s。

此过程汽车位移 x₁ = v₀t − ½at² = 12×4 − ½×2×4² = 48 − 16 = 32 m。

拖拉机位移 x₂ = v₁t = 4×4 = 16 m。

最小距离 d = x₀ + x₂ − x₁ = 20 + 16 − 32 = 4 m。

(2) 因最小距离 4 m > 0，故两车不会相撞。

3. C（受力分析与连接体）

【思路】 先用整体法求加速度，再隔离受拉力之外的那个物块求绳张力。

【解答】 系统 a = F/(m₁+m₂) = 6/(1+2) = 2 m/s²。

隔离 m₂：绳张力 T 提供其加速度，T = m₂a = 2×2 = 4 N。故选 C。

4.（斜面与传送带）

【思路】 物块速度大于带速，相对带向右滑，摩擦力向左、大小 μmg，物块减速；到共速后与带一起匀速。

【解答】 f = μmg = 0.2×1×10 = 2 N，a = f/m = 2 m/s²（减速）。

(1) 减速到 2 m/s：t = (v₀−v)/a = (4−2)/2 = 1 s。

(2) 物块位移 x = (v₀+v)/2 · t = (4+2)/2 × 1 = 3 m。

(3) 传送带位移 x带 = vt = 2×1 = 2 m，相对位移 Δs = x − x带 = 1 m。

摩擦生热 Q = f·Δs = 2×1 = 2 J。

5. B（牛顿第二定律的瞬时性）

【思路】 剪断瞬间弹簧形变量来不及改变，弹力不变；绳的拉力突变为零。

【解答】 剪断前，弹簧对 B 的拉力（向上）等于 B 的重力 mg，故弹簧对 A 的拉力（向下）也为 mg。

剪断瞬间弹簧力不变：B 受弹力 mg（向上）与重力 mg（向下）平衡，a_B = 0；

A 受重力 mg 与弹簧拉力 mg，均向下，合力 2mg，a_A = 2mg/m = 2g。故选 B。

6. C（超重与失重）

【思路】 加速度向上为超重，由牛顿第二定律求支持力（示数）。

【解答】 匀加速上升，a 向上，处于超重状态：N − mg = ma，

N = m(g+a) = 50×(10+2) = 600 N。故选 C。

7.（平抛运动）

【思路】 竖直分运动定时间，水平分运动定射程，落地速度用矢量合成。

【解答】 (1) 竖直方向 h = ½gt²，t = √(2h/g) = √(2×20/10) = 2 s。

(2) 水平方向 x = v₀t = 10×2 = 20 m。

(3) 落地竖直分速度 v_y = gt = 20 m/s，

v = √(v₀²+v_y²) = √(10²+20²) = √500 = 10√5 ≈ 22.4 m/s。

8. B（圆周运动与临界）

【思路】 绳（内轨道）模型在最高点的临界条件是重力恰好提供向心力。

【解答】 mg = mv²/R，v = √(gR) = √(10×0.4) = 2 m/s。故选 B。

9.（万有引力与天体运动）

【思路】 用黄金代换 GM = gR²，再由万有引力提供向心力求 v 和 T。

【解答】 (1) 由 GM = gR²，卫星做圆周运动：GMm/r² = mv²/r，

v = √(GM/r) = √(gR²/(4R)) = √(gR/4) = √(10×6.4×10⁶/4) = √(1.6×10⁷) = 4×10³ m/s。

(2) T = 2πr/v = 2π×(4×6.4×10⁶)/(4×10³) = 2π×6400 = 1.28×10⁴π s ≈ 4.0×10⁴ s。

10.（功和能 · 动能定理）

【思路】 先求各力做功，再对全过程用动能定理。

【解答】 摩擦力 f = μmg = 0.3×2×10 = 6 N。

(1) 合外力 F合 = F − f = 10 − 6 = 4 N，W合 = F合·s = 4×4 = 16 J。

(2) 由动能定理 W合 = ½mv² − 0：½×2×v² = 16，v² = 16，v = 4 m/s。

11.（机械能守恒）

【思路】 只有重力做功，机械能守恒。

【解答】 以地面为零势能面：mgh = ½mv²，

v = √(2gh) = √(2×10×5) = 10 m/s。

12.（动量与碰撞（一维））

【思路】 弹性碰撞同时满足动量守恒与动能守恒，可直接用弹性碰撞公式。

【解答】 v₁′ = (m₁−m₂)/(m₁+m₂)·v₀ = (2−4)/(2+4)×6 = −2 m/s；

v₂′ = 2m₁/(m₁+m₂)·v₀ = 2×2/6×6 = 4 m/s。

即 m₁ 以 2 m/s 沿原方向的反方向弹回，m₂ 以 4 m/s 沿原方向前进。

【校验】 动量 2×6 = 12；碰后 2×(−2)+4×4 = 12，守恒 ✓。

13.（人船模型）

【思路】 系统初动量为零，动量守恒 → 位移与质量成反比。

【解答】 由 m·x人 = M·x船，且 x人 + x船 = L：

60x人 = 180x船 → x人 = 3x船；3x船 + x船 = 4 → x船 = 1 m，x人 = 3 m。

船移动 1 m，方向与人行走方向相反。

14.（电场 · 库仑定律）

【思路】 直接套库仑定律，异种电荷相互吸引。

【解答】 F = kq₁q₂/r² = 9×10⁹×(4×10⁻⁸×9×10⁻⁸)/0.3²。

其中 4×10⁻⁸×9×10⁻⁸ = 3.6×10⁻¹⁵，

F = 9×10⁹×3.6×10⁻¹⁵/0.09 = 9×10⁹×4×10⁻¹⁴ = 3.6×10⁻⁴ N。

两电荷异号，故为引力。

15.（电势能与电容）

【思路】 保持与电源连接 → U 不变；用 C=Q/U 求电荷量，E=U/d 求场强。

【解答】 (1) Q = CU = 2×10⁻⁶×100 = 2×10⁻⁴ C。

(2) E = U/d = 100/(2×10⁻³) = 5×10⁴ V/m。

16.（闭合电路欧姆定律）

【思路】 先由闭合电路欧姆定律求电流，再依次求路端电压和输出功率。

【解答】 (1) I = E/(R+r) = 6/(5+1) = 1 A。

(2) 路端电压 U = IR = 1×5 = 5 V（即 U = E − Ir = 6 − 1 = 5 V）。

(3) 输出功率 P出 = UI = 5×1 = 5 W。

17.（电表改装与伏安法）

【思路】 电压表＝电流计串联大电阻；小电阻测电阻用电流表外接。

【解答】 (1) 满偏时 U = Ig(Rg + R)：3 = 2×10⁻³×(50 + R) → 50 + R = 1500 → R = 1450 Ω。

(2) 应选"外接"（电压表并联在 Rx 两端、电流表接在其外）。因为 Rx ≈ 5 Ω 属小电阻，远小于电压表内阻，外接时电压表分流引起的误差小；若内接，电流表内阻与被测电阻可比，误差大。

18.（磁场 · 安培力与洛伦兹力）

【思路】 导线与 B 垂直，用 F=BIL；电子与 B 垂直，用 F=qvB。

【解答】 (1) B = F/(IL) = 0.4/(2×0.5) = 0.4 T。

(2) f = qvB = 1.6×10⁻¹⁹×1×10⁶×0.4 = 6.4×10⁻¹⁴ N。

19.（带电粒子在磁场中的圆周运动）

【思路】 洛伦兹力提供向心力；周期与速度无关。

【解答】 (1) qvB = mv²/r → r = mv/(qB) = (8×10⁻²⁶×1×10⁵)/(1.6×10⁻¹⁹×0.5) = (8×10⁻²¹)/(8×10⁻²⁰) = 0.1 m。

(2) T = 2πm/(qB) = 2π×(8×10⁻²⁶)/(8×10⁻²⁰) = 2π×10⁻⁶ s ≈ 6.28×10⁻⁶ s。

20.（电磁感应 · 动生电动势）

【思路】 导体棒垂直切割磁感线，E=BLv；再由欧姆定律求电流。

【解答】 (1) E = BLv = 0.5×0.4×5 = 1 V。

(2) I = E/R = 1/2 = 0.5 A。

21.（交变电流与变压器）

【思路】 电压比等于匝数比；副线圈接负载求 I₂，再由功率守恒求 I₁。

【解答】 (1) U₂ = (n₂/n₁)U₁ = (200/1000)×220 = 44 V。

(2) I₂ = U₂/R = 44/44 = 1 A；理想变压器 P₁=P₂，即 U₁I₁ = U₂I₂，

I₁ = U₂I₂/U₁ = 44×1/220 = 0.2 A（也等于 (n₂/n₁)I₂ = 0.2 A）。

22.（机械波与波的图象）

【思路】 由 v = λ/T = λf 求解。

【解答】 (1) T = λ/v = 0.4/2 = 0.2 s。

(2) f = 1/T = 1/0.2 = 5 Hz（即 f = v/λ = 2/0.4 = 5 Hz）。

化学母题地图 · 高一 → 高二（人教/粤教版 新课标）

什么叫"母题"：一个模型 = 一类题的公共骨架。母题会了，同族的变式都能推。

用法：先看"题眼"能不能一眼认出来，再看"通法"是不是闭着眼能走完。认不出眼，就得回去补这一节。

配套练习见《化学母题卷_高一高二.md》，每题都标注了所对应的模型。

高一上

  • 物质的量与阿伏加德罗常数判断｜题眼：题干给"一定量物质"，问微粒数目——先把量换成 n，再乘 N_A；四个坑：状态、条件、微粒种类、是否水解｜通法：n = m/M = V/V_m = c·V = N/N_A；22.4 L/mol 只在标准状况且为气体时可用；混合物按"原子/最简式"算，遇水解、弱电解质、共价键数要另想一步
  • 一定物质的量浓度溶液配制｜题眼：给"配制 XXX mL c mol/L 溶液"，看容量瓶规格与误差分析｜通法：算—称—溶—冷—移—洗—定—摇；用量按容量瓶规格算（是溶液的体积，不是溶剂的体积）；俯视/仰视先判 V 偏大偏小，再判 c
  • 离子共存｜题眼：问"能大量共存"，先把附加条件（颜色、pH、酸碱性、由水电离的 c(H⁺)）翻译成一句话｜通法：逐对过四关——生成沉淀／气体／弱电解质、氧化还原、双水解；附加条件先砍掉一批离子
  • 离子方程式正误判断｜题眼：给出一个离子方程式问对错，看"写、拆、平、量"四字｜通法：弱电解质、难溶物、氧化物、气体一律写化学式（不拆）；查电荷守恒与原子守恒双核对；再看量比与滴加顺序是否与事实相符
  • 氧化还原（配平与电子守恒计算）｜题眼：出现化合价升降、得失电子、转移电子数｜通法：标价态→定升降→升降总数相等定系数→质量守恒补余项；计算一律用 n(氧化剂)×降价数 = n(还原剂)×升价数

高一下

  • 钠及其化合物｜题眼：Na₂O₂ 出场（−1 价 O，既是氧化剂又是还原剂）、NaHCO₃ 受热分解｜通法：2Na₂O₂ + 2H₂O = 4NaOH + O₂↑、2Na₂O₂ + 2CO₂ = 2Na₂CO₃ + O₂；Na₂O₂ 中每 1 mol 转移 1 mol e
  • 铝及其化合物的两性｜题眼：Al、Al₂O₃、Al(OH)₃ 既溶于强酸又溶于强碱；氨水、碳酸溶解不了 Al(OH)₃｜通法：看 n(OH⁻)/n(Al³⁺)：=3 沉淀最多，>3 开始溶解，≥4 完全溶解；记 Al³⁺ + 4OH⁻ = AlO₂⁻ + 2H₂O
  • 铁及其化合物（Fe²⁺/Fe³⁺ 转化）｜题眼：Fe³⁺ 遇 KSCN 变红；Fe²⁺ 要"先加 KSCN 不变红，再加氯水变红"｜通法：2Fe³⁺ + Fe = 3Fe²⁺、2Fe³⁺ + Cu = 2Fe²⁺ + Cu²⁺；按 n(Fe³⁺)/n(Fe) 比值判谁过量
  • 氯及其化合物｜题眼：Cl₂ 与碱反应、新制氯水的"三分子三离子"、漂白原理｜通法：Cl₂ + 2OH⁻ = Cl⁻ + ClO⁻ + H₂O（每 1 mol Cl₂ 转移 1 mol e）；漂白靠 HClO 而不是 Cl₂
  • 硫与氮（SO₂、硝酸）｜题眼：SO₂ 三性（酸性氧化物、漂白性、还原性）；浓硝酸→NO₂、稀硝酸→NO｜通法：Cu + 4HNO₃(浓) = Cu(NO₃)₂ + 2NO₂↑ + 2H₂O；3Cu + 8HNO₃(稀) = 3Cu(NO₃)₂ + 2NO↑ + 4H₂O；被还原的硝酸 = 生成气体的物质的量
  • 硅与无机非金属材料｜题眼：SiO₂ 是酸性氧化物但不溶于水，却能"吃掉"玻璃（HF、NaOH）｜通法：SiO₂ + 4HF = SiF₄↑ + 2H₂O、SiO₂ + 2NaOH = Na₂SiO₃ + H₂O；装 NaOH 溶液必须用橡胶塞
  • 元素周期律与位构性｜题眼：比金属性/非金属性、比半径、比氢化物稳定性与最高价含氧酸酸性｜通法：先定位到周期表的格，再套递变；半径"层多径大，同层核大径小"；比非金属性只看最高价含氧酸的酸性，不看 HCl、H₂S 水溶液的酸性

高二

  • 化学反应速率与影响因素｜题眼：给浓度变化和时间求 v；或比不同物质的速率快慢｜通法：v = Δc/Δt；比大小先归到同一物质、同一单位；速率之比 = 化学计量数之比
  • 化学平衡（K、转化率、等效平衡）｜题眼：给起始量与平衡量，求 K、转化率、浓度；或问"等效"｜通法：三段式（起始—变化—平衡）列表；K 只随温度改变；转化率 α = 转化量/起始量
  • 弱电解质的电离与 pH｜题眼：pH 相同的强酸与弱酸稀释后比较；求弱酸的 pH｜通法：pH = −lg c(H⁺)；强酸稀释 10ⁿ 倍 pH 增 n，弱酸增得小于 n（同 pH 时稀释后 c(H⁺) 反而更大）
  • 盐类水解｜题眼：比较同浓度盐溶液的 pH/离子浓度；问溶液显什么性｜通法：谁弱谁水解、谁强显谁性；越弱越水解；水解的离子方程式一般不写 ↓ 和 ↑
  • 沉淀溶解平衡（Ksp）｜题眼：问谁先沉淀、能否生成沉淀、某离子残留浓度｜通法：Qc 与 Ksp 比大小判方向；同类型难溶物，Ksp 小者先沉淀；算残留浓度直接用 Ksp ÷ 已知离子浓度
  • 原电池与电解池｜题眼：给装置图问电极反应、电子流向、产物、pH 变化｜通法：原电池"负氧正还"、电解池"阳氧阴还"；先写两个电极反应，再用电子守恒串起来配平总反应
  • 金属腐蚀与防护｜题眼：钢铁生锈、海水里的船底、镀锌与镀锡的比较｜通法：中性/弱酸性吸氧腐蚀（O₂ + 2H₂O + 4e⁻ = 4OH⁻），酸性较强则析氢腐蚀（2H⁺ + 2e⁻ = H₂↑）；保护法：牺牲阳极（接更活泼金属作负极）、外加电流阴极保护、覆盖保护层
  • 有机化学基础（同分异构与官能团性质）｜题眼：给分子式问同分异构体数目；给结构问性质｜通法：同分异构先画碳骨架、再挪官能团位置，注意对称性；性质看官能团（—OH、—CHO、—COOH、酯基、C=C）
  • 有机合成路线设计｜题眼：给原料和产物，要求写出合成路线｜通法：逆合成分析；熟记"醇→醛→酸→酯"主干和卤代烃"水解得醇、消去得烯"；每一步都注明反应条件与反应类型
  • 化学实验基本操作与检验｜题眼：检验某离子、除杂、气密性检查、操作先后顺序｜通法：检验四步"取样—加试剂—看现象—下结论"；除杂两不（不引入新杂质、不减少主体）；干扰离子要先用试剂排掉

三句话总结

1. 高一上练"量、电、离子"：物质的量是全部计算的入口，氧化还原是全部电子问题的总纲；

2. 高一下练"元素与结构"：一类金属（钠铝铁）+ 一类非金属（氯硫氮硅），全部靠"单质→氧化物→水化物→盐"这条线串起来；

3. 高二练"速率、平衡、电与有机"：主线上讲平衡（速率、K、电离、水解、沉淀）与转化（电化学、有机合成），核心工具是守恒与三段式。

【解析】A 错：Fe 与稀盐酸反应生成 FeCl₂，1 mol Fe 只失去 2 mol 电子，转移 2N_A。B 错：标准状况下乙醇是液体，不能用 22.4 L/mol。C 对：O₂ 和 O₃ 都是氧元素组成的单质，1.6 g 混合气体中氧原子 n = 1.6 g ÷ 16 g/mol = 0.10 mol，即 0.1N_A——守恒依据：原子（元素）质量守恒。D 错：CO₃²⁻ 水解，其数目小于 0.1N_A。

2. 10.0 g（一定物质的量浓度溶液配制）

【解析】实验室没有 480 mL 容量瓶，应按 500 mL 配制。n(NaOH) = 0.500 L × 0.50 mol/L = 0.250 mol，m = 0.250 mol × 40 g/mol = 10.0 g。（易错：直接把体积按 480 mL 代入。）

3. D（离子共存）

【解析】A 错：溶液显碱性，HCO₃⁻ + OH⁻ = CO₃²⁻ + H₂O，不能共存。B 错：Cu²⁺ 在溶液中显蓝色，不符合"无色"。C 错：Fe³⁺ 与 SCN⁻ 发生络合反应，不能共存。D 对：由 c(H⁺)/c(OH⁻) = 1×10¹² 及 c(H⁺)·c(OH⁻) = 1×10⁻¹⁴ 知 c(H⁺) = 0.1 mol/L，溶液强酸性，Na⁺、K⁺、Cl⁻、SO₄²⁻ 互不反应，可大量共存。

4. C（离子方程式正误判断）

【解析】A 错：产物应为 Fe²⁺，正确写法 Fe + 2H⁺ = Fe²⁺ + H₂↑（电荷：左 +2，右 +2，守恒；但产物与事实不符）。B 错：HClO 是弱酸，不能拆，应写 Cl₂ + H₂O ⇌ H⁺ + Cl⁻ + HClO。C 对：拆写正确、原子与电荷均守恒（左 0 = 右 0），且产物符合事实。D 错：醋酸是弱酸，不能拆，应写 CaCO₃ + 2CH₃COOH = Ca²⁺ + 2CH₃COO⁻ + H₂O + CO₂↑。

5. 0.50 mol；1.0 mol（氧化还原：配平与电子守恒计算）

【解析】先配平：2MnO₄⁻ + 5H₂O₂ + 6H⁺ = 2Mn²⁺ + 5O₂↑ + 8H₂O。

配平核对——Mn：2 = 2；O：2×4 + 5×2 = 18，右边 5×2 + 8 = 18；H：5×2 + 6 = 16，右边 8×2 = 16；电荷：左 2×(−1) + 6×(+1) = +4，右 2×(+2) = +4。元素与电荷守恒均通过。

电子守恒：Mn 由 +7 降到 +2，每 mol 得 5 mol e⁻；O 由 −1 升到 0，每 mol O 失 1 mol e⁻。由关系式 2MnO₄⁻ ~ 5H₂O₂ 得 n(H₂O₂) = 0.20 mol × 5/2 = 0.50 mol；转移电子 n(e⁻) = 0.20 mol × 5 = 1.0 mol（也可由 0.50 mol H₂O₂ × 2 = 1.0 mol 验证）。

6. 0.05 mol O₂；转移 0.1 mol e⁻（钠及其化合物）

【解析】n(Na₂O₂) = 7.8 g ÷ 78 g/mol = 0.10 mol。

2Na₂O₂ + 2H₂O = 4NaOH + O₂↑（原子：Na 4 = 4、O 2×2+2 = 6，右 4+2 = 6、H 4 = 4，配平）。

由关系式 2Na₂O₂ ~ O₂ 得 n(O₂) = 0.10 mol × 1/2 = 0.05 mol。

电子守恒：Na₂O₂ 中 O 为 −1 价，一半氧升到 0（O₂），一半降到 −2（OH⁻）。0.10 mol O 由 −1 升到 0 失 0.10 mol e⁻，0.10 mol O 由 −1 降到 −2 得 0.10 mol e⁻，转移电子 0.1 mol e⁻（Na₂O₂ 在这类反应中既是氧化剂又是还原剂）。

7.（1）0 g　（2）0.78 g（铝及其化合物的两性）

【解析】（1）n(OH⁻)/n(Al³⁺) = 0.040/0.010 = 4。发生 Al³⁺ + 4OH⁻ = AlO₂⁻ + 2H₂O（电荷：左 +3 − 4 = −1，右 −1，守恒；原子：Al 1 = 1、O 4 = 2+2、H 4 = 4），Al³⁺ 全部转化为偏铝酸根，沉淀质量为 0 g。

（2）氨水是弱碱，Al(OH)₃ 不溶于过量氨水：Al³⁺ + 3NH₃·H₂O = Al(OH)₃↓ + 3NH₄⁺（电荷：左 +3，右 +3，守恒；原子：Al 1 = 1、N 3 = 3、O 3 = 3、H 15 = 3+12）。0.010 mol Al³⁺ 只耗 0.030 mol NH₃·H₂O，所给 0.040 mol 过量，生成 n[Al(OH)₃] = 0.010 mol，m = 0.010 mol × 78 g/mol = 0.78 g。

8. 0.15 mol（铁及其化合物：Fe²⁺/Fe³⁺ 转化）

【解析】2FeCl₃ + Fe = 3FeCl₂（或 2Fe³⁺ + Fe = 3Fe²⁺，电荷：左 +6，右 +6，守恒；原子：Fe 3 = 3）。n(Fe³⁺) : n(Fe) = 0.10 : 0.05 = 2 : 1，恰好完全反应。由关系式 2Fe³⁺ ~ 3Fe²⁺ 得 n(Fe²⁺) = 0.10 mol × 3/2 = 0.15 mol。

9. 0.1 mol（氯及其化合物）

【解析】n(Cl₂) = 2.24 L ÷ 22.4 L/mol = 0.10 mol。Cl₂ + 2NaOH = NaCl + NaClO + H₂O，离子式 Cl₂ + 2OH⁻ = Cl⁻ + ClO⁻ + H₂O（电荷：左 −2，右 −2，守恒；原子：Cl 2 = 2、O 2 = 1+1、H 2 = 2）。Cl 一半由 0 降到 −1，一半由 0 升到 +1，每 1 mol Cl₂ 转移 1 mol e⁻，故转移 0.1 mol 电子。

10. 2.24 L；0.10 mol（硫与氮：SO₂、硝酸）

【解析】n(Cu) = 9.6 g ÷ 64 g/mol = 0.15 mol。

3Cu + 8HNO₃(稀) = 3Cu(NO₃)₂ + 2NO↑ + 4H₂O（Cu：3 = 3；N：8 = 6 + 2；O：24 = 18 + 2 + 4 = 24；H：8 = 8，配平）。

由关系式 3Cu ~ 2NO 得 n(NO) = 0.15 mol × 2/3 = 0.10 mol，V(NO) = 0.10 mol × 22.4 L/mol = 2.24 L。

被还原的硝酸即由 +5 降到 +2 的那部分，1 : 1 对应 NO，故 n(被还原 HNO₃) = n(NO) = 0.10 mol（起酸性作用的另有 0.30 mol，二者合计 0.40 mol，与方程式相符——电子守恒 + 质量守恒双核对）。

11. D（硅与无机非金属材料）

【解析】A 错：SiO₂ 虽为酸性氧化物，但不溶于水，不能与水直接反应制 H₂SiO₃（只能由可溶性硅酸盐加酸得到）。B 错：光导纤维的主要材料是 SiO₂，不是硅。C 错：常温下硅能与 NaOH 溶液反应：Si + 2NaOH + H₂O = Na₂SiO₃ + 2H₂↑（配平核对：Na 2 = 2；Si 1 = 1；O 2+1 = 3，右 3；H 2+2 = 4，右 2×2 = 4）。D 对：SiO₂ 与 NaOH 反应生成有粘性的 Na₂SiO₃，会使玻璃塞与瓶身粘住，故必须用橡胶塞。

12. D（元素周期律与位构性）

【解析】A、B、C 都能说明氯的非金属性强于硫：最高价含氧酸的酸性（HClO₄ > H₂SO₄）、单质间的置换（Cl₂ 能置换出 S）、气态氢化物的稳定性（HCl > H₂S），都是教材认可的判据。D 不能说明：非金属性的强弱应看最高价氧化物对应水化物的酸性，而 HCl 不是含氧酸、H₂S 中硫也不是最高价，两者水溶液的酸性强弱不能作为判断非金属性的依据。故选 D。

13. 0.05 mol/(L·min)（化学反应速率与影响因素）

【解析】Δn(SO₂) = 0.60 mol − 0.20 mol = 0.40 mol，Δc(SO₂) = 0.40 mol ÷ 2 L = 0.20 mol/L。

v(SO₂) = Δc/Δt = 0.20 mol/L ÷ 2 min = 0.10 mol/(L·min)。

由速率之比 = 化学计量数之比：v(O₂) = v(SO₂) × 1/2 = 0.05 mol/(L·min)。

14. K = 9；转化率 60%（化学平衡：K、转化率）

【解析】三段式（单位 mol/L，容器 1 L）：

　　H₂(g) + I₂(g) ⇌ 2HI(g)

起始　0.10　　0.10　　　0

变化　 x 　　　x 　　　 2x = 0.12 → x = 0.06

平衡　0.04　　0.04　　　0.12

K = c²(HI) / [c(H₂)·c(I₂)] = (0.12)² / (0.04 × 0.04) = 0.0144 / 0.0016 = 9。

转化率 α(H₂) = 转化量/起始量 = 0.06 / 0.10 × 100% = 60%。（质量守恒：0.10 + 0.10 = 0.04 + 0.04 + 0.12 = 0.20，I 原子守恒。）

15. ＞（弱电解质的电离与 pH）

【解析】盐酸是强酸，稀释 10 倍，c(H⁺) 由 1×10⁻² mol/L 降到 1×10⁻³ mol/L，pH₁ = 3。醋酸是弱酸，加水稀释会促进电离，稀释后 c(H⁺) 下降得比 10 倍少，仍大于 1×10⁻³ mol/L，故 pH₂ ＜ 3。所以 pH₁ ＞ pH₂。

16. ① ＞ ② ＞ ③ ＞ ④（盐类水解）

【解析】Na₂CO₃、NaHCO₃、CH₃COONa 都是强碱弱酸盐，水解显碱性，阴离子对应酸越弱、水解程度越大、碱性越强；NaCl 是强酸强碱盐，显中性（pH = 7），排最后。CO₃²⁻ 对应 HCO₃⁻（H₂CO₃ 的 Ka₂ = 5.6×10⁻¹¹），比 HCO₃⁻ 对应 H₂CO₃（Ka₁ = 4.3×10⁻⁷）弱得多，故 ① ＞ ②；HCO₃⁻ 的水解程度又明显大于 CH₃COO⁻（CH₃COOH 的 Ka = 1.8×10⁻⁵ 更大，对应酸更强、水解更弱），故 ② ＞ ③。所以顺序为 ① ＞ ② ＞ ③ ＞ ④。（注：这里比的是碱性，NaHCO₃ 溶液本身仍显碱性。）

17.（1）AgBr　（2）3.0×10⁻³（沉淀溶解平衡 Ksp）

【解析】（1）AgCl 与 AgBr 是同一类型（1 : 1）的难溶物，Ksp 越小越先沉淀。Ksp(AgBr) = 5.4×10⁻¹³ ＜ Ksp(AgCl) = 1.8×10⁻¹⁰，故先生成 AgBr。

（2）AgCl 恰好开始沉淀时，c(Ag⁺) = Ksp(AgCl) / c(Cl⁻) = 1.8×10⁻¹⁰ ÷ 0.010 = 1.8×10⁻⁸ mol/L（此时 c(Cl⁻) 仍近似为 0.010 mol/L）。

此时 Br⁻ 的残留浓度由 AgBr 的 Ksp 决定：c(Br⁻) = Ksp(AgBr) / c(Ag⁺) = 5.4×10⁻¹³ ÷ 1.8×10⁻⁸ = 3.0×10⁻⁵ mol/L。

所以 c(Br⁻)/c(Cl⁻) = 3.0×10⁻⁵ ÷ 0.010 = 3.0×10⁻³。

18.（1）阴极 Cu²⁺ + 2e⁻ = Cu；阳极 4OH⁻ − 4e⁻ = O₂↑ + 2H₂O　（2）0.28 L（原电池与电解池）

【解析】（1）石墨是惰性电极。阴极：Cu²⁺ + 2e⁻ = Cu（电荷：左 +2 + (−2) = 0，守恒）。阳极：溶液中 OH⁻ 先失电子，4OH⁻ − 4e⁻ = O₂↑ + 2H₂O（电荷：左 −4 − (−4) = 0，右 0，守恒；原子：O 4 = 2+2、H 4 = 4），也可写成 2H₂O − 4e⁻ = O₂↑ + 4H⁺。

（2）n(Cu) = 1.6 g ÷ 64 g/mol = 0.025 mol，由阴极反应知 n(e⁻) = 0.025 × 2 = 0.050 mol（电子守恒：两极转移电子数相等）。阳极由关系式 4e⁻ ~ O₂ 得 n(O₂) = 0.050 ÷ 4 = 0.0125 mol，V(O₂) = 0.0125 mol × 22.4 L/mol = 0.28 L。

19.（金属腐蚀与防护）

【解析】（1）吸氧腐蚀中，活泼的铁作负极被氧化：负极 Fe − 2e⁻ = Fe²⁺；正极（钢铁中的碳等杂质）氧气得电子：正极 O₂ + 2H₂O + 4e⁻ = 4OH⁻（电荷：把 4e⁻ 计为 −4，左端 −4 = 右端 −4，守恒；原子：O 2+2 = 4、H 4 = 4）。

两极反应叠加（用电子守恒配平，负极 ×2 得 4e⁻）：2Fe + O₂ + 2H₂O = 2Fe(OH)₂（Fe 2 = 2；O 2 + 2 = 4，右 4；H 4 = 4）。

（2）原理：锌比铁活泼，在海水电解质中锌、铁构成原电池，锌作负极被腐蚀，铁作正极被保护（牺牲阳极的阴极保护法）。只要锌块未被完全腐蚀，船体就不会被腐蚀。

20. 3 种（有机化学基础：同分异构与官能团性质）

【解析】能使溴水褪色说明含 C=C，分子式 C₄H₈ 且不考虑环状、顺反异构，即为丁烯的碳链异构与位置异构：① 1-丁烯 CH₂=CH—CH₂—CH₃；② 2-丁烯 CH₃—CH=CH—CH₃（不计顺反）；③ 2-甲基丙烯 CH₂=C(CH₃)₂。共 3 种。（环丁烷、甲基环丙烷虽也是 C₄H₈，但按题目要求不计环状结构。）

21.（有机合成路线设计）

【解析】逆合成分析：乙酸乙酯 ← 乙酸 + 乙醇；乙酸 ← 乙醛 ← 乙醇；乙醇可由乙烯水化得到。路线如下：

① CH₂=CH₂ + H₂O —催化剂/加热加压→ CH₃CH₂OH（加成反应）

② 2CH₃CH₂OH + O₂ —Cu/Δ→ 2CH₃CHO + 2H₂O（氧化反应）

　配平核对：C 2×2 = 4，右 2×2 = 4；H 2×6 = 12，右 2×4 + 2×2 = 12；O 2 + 2 = 4，右 2×1 + 2 = 4。

③ 2CH₃CHO + O₂ —催化剂/Δ→ 2CH₃COOH（氧化反应）

　配平核对：C 4 = 4；H 8 = 8；O 2×1 + 2 = 4，右 2×2 = 4。

④ CH₃COOH + CH₃CH₂OH —浓硫酸/Δ→ CH₃COOCH₂CH₃ + H₂O（酯化反应，属于取代反应）

　配平核对：C 4 = 4；H 4+6 = 10，右 8+2 = 10；O 2+1 = 3，右 2+1 = 3。

22.（化学实验基本操作与检验）

【解析】（1）先加足量稀盐酸，是为了排除 CO₃²⁻、SO₃²⁻ 等离子的干扰：它们与 Ba²⁺ 也生成白色沉淀（BaCO₃、BaSO₃），但能溶于盐酸。若加盐酸后无气体、无沉淀，说明这些离子已被排除，之后再检验才可靠。

（2）若先加 BaCl₂ 溶液，CO₃²⁻、SO₃²⁻ 也会产生白色沉淀，仅凭"有白色沉淀"就下结论会误判为含 SO₄²⁻；而且此时再加稀盐酸，若沉淀溶解，只能说明原来的是 BaCO₃/BaSO₃ 而非 BaSO₄，反倒要重做实验。规范顺序应是"先酸化排除干扰，后加 BaCl₂ 检验"，才能得出 SO₄²⁻ 的唯一结论。
